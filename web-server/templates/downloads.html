Play on {{ domain }}

  1. Download the archive and rift.env into the same folder, and extract the archive there, so desktop-client lands next to rift.env.
  2. Start desktop-client. The first start downloads the game, which takes a while. Later starts only download what changed.
  3. Click Sign in, or Create account if you have no {{ domain }} account yet. Your browser opens the sign-in page. Sign in there, then switch back to the game.

It's the same account you play in the browser with.

rift.env

desktop-client reads rift.env from its own folder. Each line sets one value, as NAME=value. Every value is required, unless it says optional. A relative path counts from the folder rift.env is in. An environment variable with the same name wins over the line in rift.env.

RIFT_CLIENT_GAME_SERVER_URL
The HTTP address of the game server to play on.
RIFT_CLIENT_GAME_SERVER_WS_URL
The WebSocket address of the same game server.
RIFT_CLIENT_AUTH
oidc: sign in with a {{ domain }} account, in your browser. fake: sign in with any name, on a server that lets anyone play as anyone.
RIFT_CLIENT_PROFILE_DIR
The folder where desktop-client keeps your preferences and the downloaded game.
RIFT_CLIENT_EXIT_ON_STDIN_EOF
true quits desktop-client when the program that started it closes its input. Otherwise false.
RIFT_CLIENT_ACCESS_TOKEN optional
Signs in with this token and skips the sign-in screen.
RIFT_CLIENT_PROBE optional
Only for automated tests.

For {{ domain }} accounts

Read only when RIFT_CLIENT_AUTH is oidc. They point at the sign-in service of {{ domain }}, so keep them as downloaded.

RIFT_AUTH_CLIENT_ID
The name the sign-in service knows the game by.
RIFT_AUTH_AUTHORIZATION_URI
The page your browser opens to sign in.
RIFT_AUTH_SIGN_UP_URI
The page your browser opens to create an account.
RIFT_AUTH_TOKEN_URI
Where desktop-client finishes a sign-in.
